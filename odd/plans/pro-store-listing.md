## Store listing — English (United States)

**Description**

EntropIA Pro is a desktop app for organizing research collections, processing documents, and enriching sources with AI, running on your own computer.
Create collections, import images, PDFs, audio, and documents, then review extracted text, transcriptions, metadata, notes, annotations, entities, summaries, triples, and search indexes from a local desktop workspace.
EntropIA Pro runs its AI locally by default: OCR (PaddleOCR, GLM-OCR), transcription (Parakeet, Whisper) with optional speaker detection, embeddings (BGE-M3), named entities (spaCy), and a local language model. On first launch it downloads its local AI runtime and models, with visible progress you can pause or retry.
Your workspace data stays on your computer. If you choose to, you can also use remote providers such as OpenRouter, Z.ai/GLM-OCR, or AssemblyAI with your own API keys, or point generation at your own OpenAI-compatible server (vLLM, Ollama).
A built-in help assistant answers questions from the user manual and can guide you through the app.

**What's new in this version**

EntropIA Pro 1.8.0 — first Microsoft Store release
 • Local transcription with Parakeet TDT, optional speaker detection, and speaker renaming.
 • Persistent local GLM-OCR engine and local OCR correction with Qwen3-VL.
 • Help assistant built on the user manual, with gated tools.
 • Internet Archive importer with batch import of PDFs and original images.

**Product features**

1. Organize research collections, items, assets, notes, and annotations.
2. Import images, PDFs, audio, and document sources into a local workspace.
3. Run OCR, transcription, summaries, embeddings, NER, and triples with local AI models.
4. Transcribe audio locally, with optional speaker detection.
5. Search with full-text search and semantic similarity.
6. Keep working offline once the local models are installed.
7. Optionally use remote AI providers or your own OpenAI-compatible server.

## Store listing — Spanish

**Descripción**

EntropIA Pro es una aplicación de escritorio para organizar colecciones de investigación, procesar documentos y enriquecer fuentes con IA que se ejecuta en tu propio equipo.
Permite crear colecciones, importar imágenes, PDFs, audio y documentos, y revisar texto extraído, transcripciones, metadatos, notas, anotaciones, entidades, resúmenes, triples e índices de búsqueda desde un espacio de trabajo local.

Los datos de trabajo quedan en el equipo del usuario. Si se desea, también se pueden usar proveedores remotos como OpenRouter, Z.ai/GLM-OCR o AssemblyAI con claves API propias, o apuntar la generación a un servidor propio compatible con OpenAI (vLLM, Ollama).
Un asistente de ayuda integrado responde preguntas a partir del manual de usuario y guía el uso de la aplicación.
