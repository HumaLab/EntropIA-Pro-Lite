# User manual — EntropIA Pro and Lite

**Español:** [Manual-de-Uso.md](./Manual-de-Uso.md)

The user manual covers both variants (Lite and Pro) and is published at
**[humalab.github.io/EntropIA-Pro-Lite/manual-usuario](https://humalab.github.io/EntropIA-Pro-Lite/manual-usuario/manual-usuario.en.html)**
(in Spanish: [manual-usuario.html](https://humalab.github.io/EntropIA-Pro-Lite/manual-usuario/manual-usuario.html)).

Its sources are [`manual/manual-usuario/manual-usuario.md`](manual/manual-usuario/manual-usuario.md)
(Spanish, the default language) and [`manual/manual-usuario/manual-usuario.en.md`](manual/manual-usuario/manual-usuario.en.md)
(English), with the [feature inventory](manual/manual-usuario/inventario-funciones-manual.en.md) in both
languages. To correct or extend the manual, edit those files and keep both editions in step: they
share anchors, images and chapter structure. This page only points there, so that there are never
two manuals contradicting each other.

The in-app help reads the Spanish edition, which is compiled into each version: whatever is
corrected there, the help learns in the next version.
