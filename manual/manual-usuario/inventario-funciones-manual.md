# Inventario de funciones de EntropIA Lite

**Versión de EntropIA:** 1.0.16 · **Actualizado:** 25 de septiembre de 2026

**Documento asociado:** [Manual de usuario](manual-usuario.md)

## Alcance

Esta lista reúne las funciones disponibles en la versión Lite actual e indica en qué capítulo del manual se explican. No incluye funciones exclusivas de Pro ni de versiones anteriores. Indicamos si una función necesita conexión a Internet, una cuenta o una clave.

El manual combina capturas reales de EntropIA Lite, detalles recortados de esas capturas y diagramas de proceso identificados como tales. Cada imagen tiene una descripción y se puede abrir a tamaño completo desde la edición web.

**Criterios de lectura:**

- **Disponible:** podés usar esta opción en la versión Lite.
- **Necesita una condición:** requiere Internet, una cuenta, una clave o texto reconocido; la tabla indica cuál.
- **No disponible:** no hay una opción para realizar esta tarea en la versión Lite actual.

## OCR, transcripción, texto y búsqueda

| Función visible | Disponibilidad / alcance | Sección del manual |
|---|---|---|
| **OCRH** | PDF, PNG y JPG/JPEG. En PDF intenta aprovechar texto nativo; cuando reconoce la imagen usa GLM-OCR por Internet. WEBP/TIFF se pueden importar, pero no enviar a este OCR. | [Cap. 1](manual-usuario.md#capitulo-1-inicio-rapido), [cap. 6](manual-usuario.md#capitulo-6-obtener-texto-de-documentos) |
| Editar o restaurar el texto reconocido | Editá en **Texto**, panel derecho. **Restaurar OCR original**, en **Texto extraído** sobre el visor, requiere un original guardado y descarta las correcciones. | [Cap. 6](manual-usuario.md#capitulo-6-obtener-texto-de-documentos) |
| **OCRC**, **OCRR/Resumen** | Necesitan texto y OpenRouter. OCRC sustituye el texto al terminar, sin aceptación posterior. Revisá corrección y resumen contra la fuente. | [Cap. 6](manual-usuario.md#capitulo-6-obtener-texto-de-documentos) |
| **STT**, editar y resumir una transcripción | STT necesita un audio admitido, Internet y AssemblyAI. Editar el texto es local; resumirlo requiere OpenRouter. | [Cap. 6](manual-usuario.md#capitulo-6-obtener-texto-de-documentos) |
| **Identificación de hablantes en audio de colección** | Selector de AssemblyAI en APIs remotas. Afecta a STT de audios importados, no al dictado. Revisá las atribuciones escuchando la fuente. | [Cap. 6](manual-usuario.md#capitulo-6-obtener-texto-de-documentos), [cap. 16](manual-usuario.md#capitulo-16-configuracion-y-herramientas-generales) |
| Copiar y descargar texto como Markdown, PDF o Word | En **Texto extraído** sobre el visor de PDF/imágenes con OCR. Audio no tiene ese menú: copiá el campo editable manualmente. | [Cap. 6](manual-usuario.md#capitulo-6-obtener-texto-de-documentos), [cap. 17](manual-usuario.md#capitulo-17-exportar-y-descargar) |
| **INDEX** | Prepara el texto del documento para búsqueda léxica, que puede incluir variantes de escritura; no busca por significado. | [Cap. 7](manual-usuario.md#capitulo-7-buscar-informacion), [cap. 8](manual-usuario.md#capitulo-8-analizar-documentos-y-colecciones) |
| **Búsquedas → Buscar por texto similar (FTS)** | Hasta 10 documentos mediante términos y variantes próximas; para buscar contenido necesita texto indexado. | [Cap. 7](manual-usuario.md#capitulo-7-buscar-informacion) |
| **EMBED** y **Assets similares** | EMBED prepara el archivo/página seleccionado con texto, OpenRouter e Internet. **Assets similares** se carga al abrir Búsquedas: hasta 5 resultados con semejanza y vista previa. | [Cap. 7](manual-usuario.md#capitulo-7-buscar-informacion), [cap. 8](manual-usuario.md#capitulo-8-analizar-documentos-y-colecciones) |
| **NER** y **TRIPLET** | Proponen nombres y relaciones; revisá o corregí cada resultado. En Lite necesitan OpenRouter. | [Cap. 8](manual-usuario.md#capitulo-8-analizar-documentos-y-colecciones) |
| **Mapa** | Permite revisar y cambiar lugares asociados a un documento. Ver el mapa y buscar lugares requiere Internet. | [Cap. 8](manual-usuario.md#capitulo-8-analizar-documentos-y-colecciones) |
| Análisis de palabras en una colección: nube, gráfico, palabras excluidas y descarga PNG | Cuenta palabras de textos reconocidos y transcripciones guardadas; no resume los documentos. | [Cap. 8](manual-usuario.md#capitulo-8-analizar-documentos-y-colecciones) |
