# Inventario de funciones de EntropIA Lite

**Versión de EntropIA:** 1.0.16 · **Actualizado:** 24 de septiembre de 2026

**Documento asociado:** [Manual de usuario](manual-usuario.md)

## Alcance

Esta lista reúne las funciones disponibles en la versión Lite actual e indica en qué capítulo del manual se explican. No incluye funciones exclusivas de Pro ni de versiones anteriores. Indicamos si una función necesita conexión a Internet, una cuenta o una clave.

Las ilustraciones del manual son diagramas orientativos, no capturas de pantalla.

**Criterios de lectura:**

- **Disponible:** podés usar esta opción en la versión Lite.
- **Necesita una condición:** requiere Internet, una cuenta, una clave o texto reconocido; la tabla indica cuál.
- **No disponible:** no hay una opción para realizar esta tarea en la versión Lite actual.

## OCR, transcripción, texto y búsqueda

| Función visible | Disponibilidad / alcance | Sección del manual |
|---|---|---|
| **OCRH** | Envía la página a GLM-OCR por Internet y requiere una clave de acceso. Admite PDF, PNG y JPG/JPEG. | [Cap. 1](manual-usuario.md#capitulo-1-inicio-rapido), [cap. 6](manual-usuario.md#capitulo-6-obtener-texto-de-documentos) |
| Editar o restaurar el texto reconocido | Disponible cuando hay un texto original; los cambios se guardan para esa página o archivo. | [Cap. 6](manual-usuario.md#capitulo-6-obtener-texto-de-documentos) |
| **OCRC**, **OCRR/Resumen** | Necesitan texto y OpenRouter. Sus propuestas pueden tener errores; revisalas con el original. | [Cap. 6](manual-usuario.md#capitulo-6-obtener-texto-de-documentos) |
| **STT**, editar y resumir una transcripción | Necesita un audio admitido, conexión a Internet y AssemblyAI. | [Cap. 6](manual-usuario.md#capitulo-6-obtener-texto-de-documentos) |
| Copiar y descargar texto como Markdown, PDF o Word | Disponible para el texto de la página o archivo seleccionado. | [Cap. 6](manual-usuario.md#capitulo-6-obtener-texto-de-documentos), [cap. 17](manual-usuario.md#capitulo-17-exportar-y-descargar) |
| **INDEX** | Prepara el texto para que puedas encontrar las mismas palabras que contiene; no busca por significado. | [Cap. 7](manual-usuario.md#capitulo-7-buscar-informacion), [cap. 8](manual-usuario.md#capitulo-8-analizar-documentos-y-colecciones) |
| **Búsquedas → Buscar por texto similar (FTS)** | Encuentra palabras presentes en el texto; puede mostrar hasta 10 documentos y necesita texto reconocido. | [Cap. 7](manual-usuario.md#capitulo-7-buscar-informacion) |
| **EMBED** y **Assets similares** | Preparan una página o archivo para compararlo con otros materiales; necesitan texto, OpenRouter y conexión a Internet. | [Cap. 7](manual-usuario.md#capitulo-7-buscar-informacion), [cap. 8](manual-usuario.md#capitulo-8-analizar-documentos-y-colecciones) |

| **Mapa** | Permite revisar y cambiar lugares asociados a un documento. Ver el mapa y buscar lugares requiere Internet. | [Cap. 8](manual-usuario.md#capitulo-8-analizar-documentos-y-colecciones) |
| Análisis de palabras en una colección: nube, gráfico, palabras excluidas y descarga PNG | Cuenta palabras de textos reconocidos y transcripciones guardadas; no resume los documentos. | [Cap. 8](manual-usuario.md#capitulo-8-analizar-documentos-y-colecciones) |

| Reconstruir una colección desde **Exportar JSON** | No podés volver a importar ese archivo en EntropIA. | [Cap. 4](manual-usuario.md#capitulo-4-crear-y-organizar-un-corpus) |
