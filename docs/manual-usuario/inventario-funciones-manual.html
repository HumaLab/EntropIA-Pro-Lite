Inventario de funciones de EntropIA Lite

Versión de EntropIA: 1.0.16 · Actualizado: 25 de septiembre de 2026

Documento asociado: Manual de usuario

Alcance

Esta lista reúne las funciones disponibles en la versión Lite actual e indica en qué capítulo del manual se explican. No incluye funciones exclusivas de Pro ni de versiones anteriores. Indicamos si una función necesita conexión a Internet, una cuenta o una clave.

Las ilustraciones del manual son diagramas orientativos, no capturas de pantalla.

Criterios de lectura:

  • Disponible: podés usar esta opción en la versión Lite.
  • Necesita una condición: requiere Internet, una cuenta, una clave o texto reconocido; la tabla indica cuál.
  • No disponible: no hay una opción para realizar esta tarea en la versión Lite actual.

Navegación general y preferencias

Función visible Disponibilidad / alcance Sección del manual
Colecciones en la pantalla inicial; filtro por nombre Disponible; el filtro ayuda a encontrar colecciones, pero no cambia su orden. Cap. 1, cap. 4
Accesos superiores: Chat de investigación, Agente de investigación, Escritura, Base de datos, Configuración Disponible; las vistas se llaman Investigar y Consulta DB. Cap. 1, cap. 10, cap. 13
Pestañas de trabajo, hasta 4; abrir, elegir y cerrar Disponible. Cada pestaña conserva su recorrido. La última no se cierra. Cap. 1
Vista dividida Disponible. Muestra dos pestañas; la división se puede arrastrar y los paneles se apilan si la ventana es angosta. Cap. 1
Explorador en vista dividida Disponible como panel sobre el área activa; empieza cerrado. En una sola pantalla sigue a la izquierda y Ctrl+B lo oculta. Cap. 1, cap. 4
Ruta de cada pestaña; documento anterior/siguiente; Eliminar página activa Disponible en la ruta de esa pestaña. Eliminar una página o archivo citado puede dejar la cita sin abrir la fuente, y la quita de las otras pestañas. Cap. 5
Búsqueda de la barra superior Disponible; busca títulos, datos descriptivos y texto reconocido. No responde preguntas temáticas con IA. Cap. 1, cap. 7
Tema Oscuro, Cálido, Claro, Lite; contraste suave/normal/alto Disponible. Lite también es el nombre de un tema visual; no cambia la versión instalada. Cap. 16
Zoom de interfaz de 75 a 125 %; atajos Ctrl+/Ctrl−/Ctrl0 Disponible. Cap. 16
Tipografía Académica, Moderna, Editorial, Archivo; idioma ES/EN Disponible. El idioma cambia los textos de la interfaz, no los documentos. Cap. 16
Versión, enlaces a GitHub/HLab, estado de sincronización y lotes, notificaciones Disponible; algunas indicaciones dependen de que hayas iniciado sesión. Cap. 15, cap. 16
Aviso Ver actualización Puede abrir la ficha de Microsoft Store; no instala la actualización. Cap. 16

Colecciones, documentos y visor

Función visible Disponibilidad / alcance Sección del manual
Crear, editar y eliminar colecciones Disponible; al eliminar una colección, también se elimina su contenido asociado. Cap. 4
Filtrar colecciones y buscar documentos Disponible; no hay una opción para ordenar las colecciones manualmente. Cap. 4
Importar uno o varios archivos con el selector o arrastrándolos Disponible para los formatos indicados en el manual; importar no reconoce texto ni transcribe audio automáticamente. Cap. 1, cap. 4
Importar PDF, PNG/JPG/JPEG, WEBP, TIFF/TIF y WAV/MP3/FLAC/M4A/AAC/OGG Disponible. No todos los formatos que se pueden importar sirven para reconocer texto. Cap. 4, cap. 6
Cada archivo importado crea un documento y se guarda como copia en este equipo Disponible; un PDF de varias páginas se recorre hoja por hoja. Si importás otra vez el mismo archivo sin cambios, puede omitirse. Cap. 4
Exportar datos de una colección como JSON (un archivo con datos) Disponible. No incluye los PDF, imágenes ni audios originales y no permite reconstruir la colección en EntropIA. Cap. 4, cap. 17
Abrir colecciones, documentos y sus páginas o archivos Disponible; podés recorrerlos, pero no editar ni ordenar sus páginas desde el explorador. Cap. 4, cap. 5
Visor de PDF e imagen: zoom, mano, anotación, recorte, cubrir región, rotación, duplicado, deshacer/rehacer Disponible para los tipos de archivo que abre el visor. Cap. 5
Reproductor de audio Disponible: reproducción, posición, saltos y volumen. Cap. 5
Eliminar documento o página/archivo abierto Disponible; la cita puede conservar el pasaje, pero dejar de abrir el documento original. Cap. 5
Pestañas del documento: Documento, Texto extraído, Notas, Texto, Análisis, Mapa, Búsquedas, Layout, Metadatos Aparecen según el tipo de página o archivo y los datos disponibles. Cap. 5
Layout: mostrar zonas detectadas, filtrarlas y copiar sus datos Necesita que la página tenga secciones detectadas; no se usa con audio. Cap. 5, cap. 8
Datos del archivo y datos personalizados Los datos del archivo se pueden consultar; podés agregar, cambiar o quitar datos personalizados. No hay opción para cambiar el nombre del documento desde este panel. Cap. 5

OCR, transcripción, texto y búsqueda

Función visible Disponibilidad / alcance Sección del manual
OCRH Envía la página a GLM-OCR por Internet y requiere una clave de acceso. Admite PDF, PNG y JPG/JPEG. Cap. 1, cap. 6
Editar o restaurar el texto reconocido Disponible cuando hay un texto original; los cambios se guardan para esa página o archivo. Cap. 6
OCRC, OCRR/Resumen Necesitan texto y OpenRouter. Sus propuestas pueden tener errores; revisalas con el original. Cap. 6
STT, editar y resumir una transcripción Necesita un audio admitido, conexión a Internet y AssemblyAI. Cap. 6
Copiar y descargar texto como Markdown, PDF o Word Disponible para el texto de la página o archivo seleccionado. Cap. 6, cap. 17
INDEX Prepara el texto para que puedas encontrar las mismas palabras que contiene; no busca por significado. Cap. 7, cap. 8
Búsquedas → Buscar por texto similar (FTS) Encuentra palabras presentes en el texto; puede mostrar hasta 10 documentos y necesita texto reconocido. Cap. 7
EMBED y Assets similares Preparan una página o archivo para compararlo con otros materiales; necesitan texto, OpenRouter y conexión a Internet. Cap. 7, cap. 8
NER y TRIPLET Proponen nombres y relaciones; revisá o corregí cada resultado. En Lite necesitan OpenRouter. Cap. 8
Mapa Permite revisar y cambiar lugares asociados a un documento. Ver el mapa y buscar lugares requiere Internet. Cap. 8
Análisis de palabras en una colección: nube, gráfico, palabras excluidas y descarga PNG Cuenta palabras de textos reconocidos y transcripciones guardadas; no resume los documentos. Cap. 8

Notas, Chat e Investigación

Función visible Disponibilidad / alcance Sección del manual
Tópicos y notas asociadas a un documento o una página Disponible; podés editar y eliminar notas, con confirmación antes de borrar. Cap. 9
Dictado en notas Necesita permiso de micrófono, AssemblyAI y conexión a Internet. Cap. 9, cap. 16
Chat de investigación Responde preguntas sobre tus documentos y puede mostrar las fuentes. Necesita OpenRouter e Internet; no busca en la Web ni permite elegir una colección. Cap. 13
Historial del Chat: buscar, renombrar, iniciar o eliminar conversaciones; descargar conversación en PDF Disponible en la vista del Chat. Cap. 13, cap. 17
Profundizar con el Agente desde el Chat Envía la última pregunta y parte de la conversación a Investigar; revisá las fuentes antes de confiar en el resultado. Cap. 13
Crear una investigación y elegir colecciones Disponible; necesita al menos una colección, OpenRouter y conexión a Internet. Cap. 10
Revisar preguntas, el plan de investigación y las búsquedas Disponible; podés responder, modificar las propuestas y continuar. Las búsquedas no consultan la Web pública. Cap. 10
Pausar, continuar o cancelar; ajustar límites de llamadas y costo Disponible según el estado del trabajo; ajustá los límites mientras esté pausado. Cap. 10
Informe con secciones, fuentes y citas; editar o reescribir Disponible al terminar el proceso; comprobá cada afirmación en la fuente original. Cap. 10
Historial de investigaciones y eliminación con confirmación Disponible; al borrar, también se elimina el informe y su información asociada. Cap. 10
Descargar un informe como Markdown, HTML o DOCX Disponible; no hay opción PDF en la pantalla del informe. Cap. 10, cap. 17

Escritura, Zotero y Agente

Función visible Disponibilidad / alcance Sección del manual
Crear manuscrito, editar el título, guardado automático, estado, contador de cambios y eliminación confirmada Disponible. Un manuscrito Sin título y vacío se reutiliza al pedir otro. Escritura solo puede estar abierta en una pestaña. No hay opción para importar DOCX/Markdown, abrir versiones anteriores o recuperar un manuscrito eliminado. Cap. 1, cap. 11
Editor: formato, tablas, búsqueda/reemplazo, títulos, imágenes PNG/JPG/GIF Disponible; podés insertar imágenes desde el selector, pegarlas o arrastrarlas. Cap. 11
Dictado en Escritura Necesita micrófono, AssemblyAI y conexión a Internet en Lite. Cap. 11
Panel Corpus, Zotero, Notas, Agente, Exportar Disponible. Corpus busca texto reconocido y muestra hasta 20 resultados; puede encontrar variantes de escritura y crear una cita vinculada al pasaje. Cap. 11
Insertar notas como texto o vínculo; crear una nota desde una selección Disponible; no podés limitar la búsqueda a las colecciones del manuscrito. Si la nota cambia o desaparece, el manuscrito conserva su texto. Cap. 9, cap. 11
Agente de Escritura: 14 acciones y revisión de propuestas Necesita OpenRouter y una selección de texto. Propone reemplazar, insertar debajo o descartar; no cambia el manuscrito hasta que elijas. Cap. 13
Conectar Zotero en el mismo equipo Necesita que Zotero esté abierto y permita la conexión con EntropIA. Puede seguir mostrando referencias consultadas antes. No requiere una cuenta web ni una clave de Zotero en EntropIA. Cap. 12
Buscar y citar referencias; ajustar la página o el capítulo citado Disponible; APA es el estilo inicial y no se puede elegir otro desde EntropIA. Cap. 12
Preferencias de cita y bibliografía Disponible al descargar; podés elegir notas al pie, referencia breve, comentario o texto citado, e incluir la bibliografía de Zotero. Cap. 17
Descargar manuscrito como Markdown, HTML o DOCX Disponible. Escritura no ofrece descarga PDF; el formato de las citas puede variar según el archivo elegido. Cap. 11, cap. 17

Lotes, sincronización y configuración

Función visible Disponibilidad / alcance Sección del manual
Procesar por lote el reconocimiento de texto o la comparación de materiales Disponible desde Configuración → Lotes; podés revisar los documentos antes de iniciar. Cap. 14
Ver el avance, pausar, reanudar o cancelar; revisar tareas fallidas e historial Disponible según el estado; el proceso se detiene al cerrar EntropIA. Cap. 14
Sincronización opcional: manual o automática, intervalo, equipos conectados, espacio y diferencias Disponible cuando iniciás sesión. No podés cambiar la dirección del servicio ni elegir colecciones por separado. Cap. 15
Volver a comprobar archivos y borrar datos del servidor Disponible con advertencias; borrar los datos remotos no elimina los de este equipo. La sincronización no es una copia de respaldo. Cap. 15
Manuscritos de Escritura en la sincronización general No se sincronizan; permanecen en el equipo donde se crearon. Cap. 11, cap. 15
APIs remotas, Prompts, Model Params, RAG Params, Sincronización, Lotes, Logs Pestañas disponibles en Configuración Lite; no aparece Dependencias de IA. Cap. 16
OpenRouter, AssemblyAI, GLM-OCR/z.ai; probar conexión y guardar OpenRouter ayuda con texto, Chat y análisis; AssemblyAI transcribe audio y habilita dictado; GLM-OCR reconoce texto de PDF e imágenes compatibles. Cap. 6, cap. 16
Base de datos → Consulta DB Permite consultar, buscar y ordenar los datos de una tabla y descargarla como JSON/CSV. No es una copia de respaldo completa. Cap. 16, cap. 17

Funciones que Lite no incluye

Función Qué conviene saber Referencia relacionada
Reconocer texto sin conexión (OCRL) y usar modelos locales de Pro Lite reconoce texto por Internet con OCRH; no ofrece los modelos locales de Pro. Cap. 6, cap. 16
Reconocimiento de texto o transcripción automáticos al importar Al importar se agregan los archivos; después tenés que iniciar el reconocimiento o la transcripción. Cap. 4
Importar .txt, Word, Excel u otros archivos de Office No hay una opción para importar esos formatos. Cap. 4
Reconstruir una colección desde Exportar JSON No podés volver a importar ese archivo en EntropIA. Cap. 4
Guardar o recuperar una copia completa de documentos, archivos y datos No hay una opción que guarde y restaure todo en un solo paso. Cap. 15, cap. 17
Buscar libremente por significado o sinónimos La búsqueda de texto encuentra palabras iguales; Assets similares compara materiales que preparaste para buscar semejanzas. Cap. 7
Buscar en Internet o en bases bibliográficas desde Chat o Investigar Estas herramientas consultan los documentos seleccionados. Zotero se consulta cuando está abierto en el mismo equipo. Cap. 10, cap. 12, cap. 13
Elegir colecciones para el Chat El Chat usa los documentos disponibles. Para limitar el material, elegí colecciones en Investigar. Cap. 10, cap. 13
Cambiar la dirección del servicio de sincronización o sincronizar colecciones por separado No hay una opción para cambiar la dirección del servicio ni elegir colecciones individuales. Cap. 15
Agregar una página a un documento existente, mover documentos entre colecciones u ordenar páginas No hay opciones para realizar esas tareas. Cap. 4, cap. 5
Sincronizar manuscritos de Escritura o importar un archivo como nuevo manuscrito Los manuscritos de Escritura no se sincronizan y no hay una opción para importar archivos como manuscritos. Cap. 11, cap. 15
Ver versiones anteriores, restaurarlas o recuperar manuscritos eliminados No hay una lista de versiones ni una papelera para recuperar manuscritos. Cap. 11
Elegir otro estilo de cita o administrar bibliotecas Zotero desde EntropIA APA es el estilo inicial; Zotero se administra desde la propia aplicación Zotero. Cap. 12
Descargar PDF desde Escritura o desde un informe de Investigar No hay descarga PDF en esas pantallas; sí se puede descargar como PDF el texto reconocido y la conversación del Chat. Cap. 10, cap. 17
Escribir una instrucción propia para el Agente de Escritura No hay un campo para escribir instrucciones; podés elegir entre las acciones disponibles para el texto seleccionado. Cap. 13
Resumir muchos documentos a la vez con los lotes Los lotes reconocen texto y preparan materiales para compararlos; no crean un resumen general. Cap. 14
