# Citation Source Landing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make citation navigation open extracted text, mark the exact persisted range across DOM nodes, and center it in view.

**Architecture:** Extend the existing rendered/raw alignment with a verified inverse operation. Replace fragment-text searching with raw-offset marking split safely across rendered text nodes, then make citation arrival a one-shot pane-selection event in `ItemAssetPanel`.

**Tech Stack:** TypeScript, Svelte 5 runes, DOM Range APIs, Vitest, Testing Library, happy-dom.

## Global Constraints

- Citation creation, persistence, and integrity verification remain unchanged.
- Mapping failure opens extracted text but never guesses or partially highlights.
- A normal asset change without a citation still opens `Documento`.
- Scroll alignment is `scrollIntoView({ block: 'center' })`.
- Every production change follows RED → GREEN with the focused command shown below.

- [ ] **Step 1: Write failing inverse-mapping tests**

Add a helper that renders the real OCR HTML, computes a raw fragment's offsets, and calls `toVisible`. Assert that a range crossing Markdown emphasis and paragraphs returns text spanning the complete rendered passage. Add a repeated-phrase case where the raw offsets select the second occurrence.

```ts
async function show(raw: string, fragment: string, occurrence = 0) {
  const visible = await visibleTextOf(raw)
  let rawStart = -1
  for (let index = 0; index <= occurrence; index += 1) {
    rawStart = raw.indexOf(fragment, rawStart + 1)
  }
  const range = mapRenderedText(visible, raw).toVisible(rawStart, rawStart + fragment.length)
  return range && visible.slice(range.start, range.end)
}

it('maps a raw range across formatting and paragraphs back to all visible words', async () => {
  const raw = 'Primero **termina aquí**\n\nSegundo empieza acá'
  expect(await show(raw, 'termina aquí**\n\nSegundo empieza')).toBe(
    'termina aquíSegundo empieza'
  )
})

it('maps raw offsets to the selected repeated occurrence', async () => {
  expect(await show('eco primero\n\neco segundo', 'eco', 1)).toBe('eco')
})
```

Assert all marked text joins to the complete visible citation, the existing elements survive, and only the first mark receives centered scrolling.
```ts
it('marks the complete source range across formatting and paragraphs', () => {
  const raw = 'antes **molino** gira\n\ndespués sigue'
  const container = render('<p>antes <strong>molino</strong> gira</p><p>después sigue</p>')
  const start = raw.indexOf('molino')
  const end = raw.indexOf('sigue') + 'sigue'.length

  expect(highlightCitationRange(container, raw, { start, end })).toBe(true)
  expect([...container.querySelectorAll('mark.citation-hit')].map((mark) => mark.textContent).join(''))
    .toBe('molino giradespués sigue')
  expect(container.querySelector('strong')?.textContent).toBe('molino')
  expect(Element.prototype.scrollIntoView).toHaveBeenCalledTimes(1)
  expect(Element.prototype.scrollIntoView).toHaveBeenCalledWith({ block: 'center' })
})
```
